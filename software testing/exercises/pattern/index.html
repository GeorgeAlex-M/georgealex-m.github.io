🔍 Pattern Testing Challenge

Find the hidden pattern using minimum tests

🎯 Mission Briefing

Your Mission: This application is looking for a specific pattern in the input you provide. Your goal is to identify and describe that pattern using the minimum possible number of tests.

How it works: Each test consists of entering text into the input field below and clicking Submit. The program will tell you whether your input matches the hidden pattern.

🚀 Getting Started

Here are three examples that match the pattern:

2, 4, 6
4, 6, 8
6, 8, 10

Strategy Tips: Think systematically about what these examples have in common. Try variations to test your hypotheses about the pattern!
